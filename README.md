## BG2EE Forced Slayer Transform

This mod causes Gorion's Ward to automatically transform into the Slayer upon the death of their romance partner. For modded characters, edit the variables.txt file prior to installation. You can also adjust the chance of a transform through editing the numerator and denominator variables in variables.txt.

Installation instructions: Download the Release archive, extract it to the folder containing baldur.exe, and run setup-ForcedSlayerTransform.exe. Install this mod after any NPC mods.
